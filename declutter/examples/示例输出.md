## 对照图长什么样

一张 png，白底，两栏等高并排。画布是 1848 × 799 CSS px（4:3 横图）/ 1848 × 1324（3:4 竖图），
截图带 `--force-device-scale-factor=2`，所以出来的 png 是 **3696 × 1598** 和 **3696 × 2648**，每栏 1800 物理像素。
（本机实测过。iPhone 的 4032px 原图压到每栏 1800px 还是 2 倍多的下采样，所以查缺陷不能只看这张，见下面报告里的第 2 条。）文字示意：

```
┌──────────────────────────────┬──────────────────────────────┐
│      原图 BEFORE（灰底条）     │    处理后 AFTER（浅绿底条）    │
├──────────────────────────────┼──────────────────────────────┤
│                              │                              │
│   客厅：地上四个纸箱、沙发边   │   客厅：纸箱没了、插排和电线   │
│   一条插排拖到墙角、茶几上     │   没了、茶几清空。            │
│   两个杯子一叠快递单。        │                              │
│                              │   ── 结构一模一样：           │
│   墙角那道从天花斜下来的裂缝、 │      墙角的裂缝还在、         │
│   地板右下三块起翘的木纹。     │      地板起翘还在、           │
│                              │      地板拼缝走向没变、       │
│                              │      窗外还是对面那栋楼、     │

 这张对照图每栏只有 1800 物理像素：拿它看整体有没有跑偏。查「裂缝 / 水渍 / 发霉还在不在」必须打开
```
