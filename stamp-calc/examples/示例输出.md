# stamp-calc 示例输出

五个完整例子。每一档乘法和每一步加法都写出来了，可以逐位复核。
所有数字按「税率截至 2026-09-17」的表算，速算口径。SKILL.md 的「输出格式」一节点名要求先读完这份再出活。

| 例 | 演示的是什么 |
|---|---|
| 例 1 | 公民第二套私宅：ABSD 占大头；**必问未偿房贷笔数** |
| 例 2 | PR 第一套两个年限方案：年限动了 LTV 就降档；TDSR 差 S$42.75 也是不过；反算最大可贷本金 |
| 例 3 | 外国人私宅：ABSD 60%；**外国人没有 CPF OA，首付全现金**；先确认 FTA 国籍 |
| 例 4 | **估价低于成交价**（两个基数 + COV 全现金）＋ **佣金收入打 haircut** ＋ HDB 的 MSR 卡口 |
| 例 5 | **非住宅商铺**：走非住宅 BSD 表、**不缴 ABSD**、压测 5%、贷款成数问 banker |

本文件里每个数字都用 `scripts/calc.py` 复核过；那个脚本的 `--dry-run` 就是拿这些例子的结果当断言（36 项）。
`(1+i)^n` 一律工具求值，不心算（SKILL.md 红线 9）。

## 例 1 · 公民买第二套私宅 $1,800,000，贷 75%、25 年

### 输入（用户原话）

> 「我客户新加坡公民，名下已经有一套私宅（贷款已经还完了），现在要买第二套，180 万，想贷 75%、25 年。他 38 岁，月收入 1.5 万，没有车贷没有其他分期。算一下要准备多少钱。」

补问了一句：**第一套的房贷还着没有？** → 已还完，名下 **0 笔未偿房贷**。
（这句不问就会把 LTV 从 75% 误当成 45%，首付差 54 万。）

### 税率截至 2026-09-17 · 税率和规则会变，算完对一眼 IRAS 官网

### 表一：印花税

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| 税基 | 只给了成交价 $1,800,000，未提供估价 → 税基和贷款基数都按成交价算 | 1,800,000 |
| BSD 第 1 档 | 180,000 × 1% | 1,800 |
| BSD 第 2 档 | 180,000 × 2% | 3,600 |
| BSD 第 3 档 | 640,000 × 3% | 19,200 |
| BSD 第 4 档 | 500,000 × 4% | 20,000 |
| BSD 第 5 档 | 剩余 1,800,000 − 1,500,000 = 300,000 × 5% | 15,000 |
| **BSD 小计** | 1,800 + 3,600 = 5,400；+19,200 = 24,600；+20,000 = 44,600；+15,000 = **59,600** | **59,600** |
| ABSD | 身份 SC · 第 2 套 → 20%；1,800,000 × 20% | 360,000 |
| **印花税合计** | 59,600 + 360,000 | **419,600** |

分档宽度自检：180,000 + 180,000 + 640,000 + 500,000 + 300,000 = **1,800,000** ✓（等于税基，说明没漏档没重复）
速记对答案：累计到 $1,500,000 的 BSD 是 $44,600 ✓，再加顶上 30 万的 5% = $15,000 → $59,600 ✓

### 表二：首付与贷款

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| LTV 判定 | 未偿房贷 0 笔 → 75% / 55% 两档；年限 25 ≤ 30 年 ✓；38 + 25 = 63 ≤ 65 ✓ → **不降档，用 75%** | 75% |
| 贷款额 | 1,800,000 × 75% | 1,350,000 |
| 首付总额 | 1,800,000 − 1,350,000 | 450,000 |
| └ 最低现金部分 | 1,800,000 × 5% | 90,000 |
| └ 可用 CPF OA 或现金 | 450,000 − 90,000 | 360,000 |
| 印花税合计（不能贷款） | 表一 | 419,600 |
| **开工前要准备的现金（最低口径）** | 90,000 + 419,600 | **509,600** |

### 表三：月供与 TDSR

| 项 | 计算过程 | 结果 |
|---|---|---|
| 月数 n | 25 × 12 | 300 |
| 压力测试利率 | 住宅 4%（客户还没拿到 thereafter rate，取 4%） | 4.00% |
| 月利率 i | 0.04 / 12 | 0.00333333 |
| (1+i)^300 | | 2.71376516 |
| i × (1+i)^300 | 0.00333333 × 2.71376516 | 0.00904588 |
| 分子 | 1,350,000 × 0.00904588 | 12,211.94 |
| 分母 | 2.71376516 − 1 | 1.71376516 |
| **压力测试月供** | 12,211.94 / 1.71376516 | **S$7,125.80** |
| 参考月供（市场约 1.45%） | 同公式，i = 0.0145/12 = 0.00120833，n = 300 | S$5,367.48 |
| 认可收入 | 问过了：15,000 **全部是固定工资**，没有佣金 / 奖金 → 15,000 + 0 × 70% | 15,000 |
| TDSR 额度 | 15,000 × 55% = 8,250；减现有债务 0 | 8,250 |
| TDSR 判定 | 7,125.80 ≤ 8,250 → **过**，余量 8,250 − 7,125.80 = 1,124.20 | 过 |
| 反推最低收入门槛 | 7,125.80 / 0.55（**按全额固定收入算的下限**） | S$12,956 / 月 |
| MSR | 私宅，不适用 | 不适用 |

### 一句话结论

公民第二套买 S$1,800,000 私宅：印花税合计 **S$419,600**（BSD 59,600 + ABSD 360,000），首付 **S$450,000**（其中现金至少 S$90,000），贷 S$1,350,000 / 25 年，压力测试月供约 **S$7,126**，TDSR **过**（月收入需 S$12,956 以上，他 S$15,000）。

### 这个例子要特别说的两件事

1. **ABSD 占了印花税的 86%。** 第二套的 20% ABSD 是 36 万，BSD 只有 5.96 万。客户问「印花税怎么这么贵」，答案在 ABSD 不在 BSD。
2. **如果他是夫妻联名、并且打算卖掉第一套** → 可能命中夫妻 ABSD 退税：第一套在「第二套购买日后 6 个月内」卖出、退税申请在出售日后 6 个月内提出，条件共七条（见 SKILL.md）。
   **但现金上要按缴了 36 万算**——先全额缴、卖掉再退，IRAS 明确 6 个月期限不予延长。不要因为「能退」就把 ABSD 写成 0。
3. 如果第一套的房贷**还在还**，LTV 会从 75% 掉到 **45%**：贷款额变 810,000，首付变 990,000，最低现金首付比例变 25%（= 450,000），压力测试月供变约 S$4,275。**差别巨大，所以这一项必问。**

## 例 2 · PR 买第一套 $1,200,000，两个年限方案

### 输入（用户原话）

> 「PR 客户，第一套房，看的私宅 120 万。42 岁，月收入 9 千，没有其他贷款。他想贷 30 年，月供越低越好。」

名下未偿房贷：0 笔。房型：私宅（只看 TDSR，不看 MSR）。

### 税率截至 2026-09-17 · 税率和规则会变，算完对一眼 IRAS 官网

### 表一：印花税（两个方案一样，印花税跟贷款无关）

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| 税基 | 成交价 1,200,000（无估价 → 贷款基数同为 1,200,000） | 1,200,000 |
| BSD 第 1 档 | 180,000 × 1% | 1,800 |
| BSD 第 2 档 | 180,000 × 2% | 3,600 |
| BSD 第 3 档 | 640,000 × 3% | 19,200 |
| BSD 第 4 档 | 剩余 1,200,000 − 1,000,000 = 200,000 × 4% | 8,000 |
| **BSD 小计** | 1,800 + 3,600 = 5,400；+19,200 = 24,600；+8,000 = **32,600** | **32,600** |
| ABSD | 身份 SPR · 第 1 套 → 5%；1,200,000 × 5% | 60,000 |
| **印花税合计** | 32,600 + 60,000 | **92,600** |

分档宽度自检：180,000 + 180,000 + 640,000 + 200,000 = **1,200,000** ✓
速记对答案：累计到 $1,000,000 的 BSD 是 $24,600 ✓，再加 20 万的 4% = $8,000 → $32,600 ✓

### 方案 A：30 年（他原本想要的）

| 项 | 计算过程 | 结果 |
|---|---|---|
| LTV 判定 | 未偿房贷 0 笔；年限 30 ≤ 30 ✓，但 **42 + 30 = 72 > 65** → **掉较低档 55%** | 55% |
| 贷款额 | 1,200,000 × 55% | S$660,000 |
| 首付总额 | 1,200,000 − 660,000 | S$540,000 |
| └ 最低现金部分 | 较低档最低现金首付 10%：1,200,000 × 10% | S$120,000 |
| └ 可用 CPF OA 或现金 | 540,000 − 120,000 | S$420,000 |
| 月数 n | 30 × 12 | 360 |
| (1+i)^360，i = 0.04/12 | | 3.31349801 |
| i × (1+i)^360 | 0.00333333 × 3.31349801 | 0.01104499 |
| 分子 | 660,000 × 0.01104499 | 7,289.70 |
| 分母 | 3.31349801 − 1 | 2.31349801 |
| **压力测试月供** | 7,289.70 / 2.31349801 | **S$3,150.94** |
| 参考月供（1.45%，30 年） | | S$2,261.99 |
| 认可收入 | 9,000 全部固定工资（问过，无佣金 / 奖金） | 9,000 |
| TDSR 额度 | 9,000 × 55% − 0 | 4,950 |
| TDSR 判定 | 3,150.94 ≤ 4,950 → **过**，余量 1,799.06 | 过 |
| 现金最低口径 | 120,000 + 92,600 | **S$212,600** |

### 方案 B：23 年（42 + 23 = 65，刚好不超 65，LTV 保住 75%）

| 项 | 计算过程 | 结果 |
|---|---|---|
| LTV 判定 | 年限 23 ≤ 30 ✓；42 + 23 = 65，**未超过** 65 ✓ → 用 **75%** | 75% |
| 满额贷款 | 1,200,000 × 75% | S$900,000 |
| 月数 n | 23 × 12 | 276 |
| (1+i)^276 | | 2.50545428 |
| i × (1+i)^276 | 0.00333333 × 2.50545428 | 0.00835151 |
| 分子 | 900,000 × 0.00835151 | 7,516.36 |
| 分母 | 2.50545428 − 1 | 1.50545428 |
| 压力测试月供（满额贷） | 7,516.36 / 1.50545428 | S$4,992.75 |
| TDSR 额度 | 9,000 × 55% | 4,950 |
| TDSR 判定 | 4,992.75 > 4,950 → **不过，差 S$42.75** | 不过 |

**不过就反算最大可贷本金**（M = 4,950，i = 0.04/12，n = 276）：

```
P = M × [(1+i)^n − 1] / [ i × (1+i)^n ]
P = 4,950 × 1.50545428 / 0.00835151
  = 7,451.99868 / 0.00835151
  = S$892,293
```

| 项 | 计算过程 | 结果 |
|---|---|---|
| 最大可贷（TDSR 卡住） | 上式 | S$892,293 |
| 实际 LTV | 892,293 / 1,200,000 | 74.36%（未触及 75% 上限） |
| 首付总额 | 1,200,000 − 892,293 | S$307,707 |
| └ 最低现金部分 | 1,200,000 × 5% | S$60,000 |
| └ 可用 CPF OA 或现金 | 307,707 − 60,000 | S$247,707 |
| 压力测试月供（按 892,293） | = TDSR 额度上限 | S$4,950 |
| 参考月供（1.45%，23 年，按 892,293） | | 约 S$3,804 |
| 现金最低口径 | 60,000 + 92,600 | **S$152,600** |

### 一句话结论

PR 第一套买 S$1,200,000 私宅：印花税合计 **S$92,600**（BSD 32,600 + ABSD 60,000）。
30 年方案因为期限过 65 岁，LTV 降到 55%，只能贷 S$660,000、首付 S$540,000（现金至少 S$120,000），压力测试月供约 S$3,151，TDSR 过。
23 年方案 LTV 保住 75%，但 TDSR 只撑得住 S$892,293（差 S$42.75 就满不了 90 万），首付 S$307,707（现金至少 S$60,000），压力测试月供顶到额度上限 S$4,950。
**两个方案差的是现金压力和总利息，选哪个是他和 banker 的事，本速算不代选。**

### 这个例子要特别说的三件事

1. **年限一改，LTV 跟着改。** 30 年方案的月供更低，但首付多出 S$232,293、现金多出 S$60,000。客户以为「拉长年限只是月供变低」，实际是 LTV 从 75% 掉到 55%。
2. **TDSR 差 42 块也是不过。** 方案 B 的瓶颈不是 LTV 而是收入。要贷满 90 万，月收入至少 4,992.75 / 0.55 = **S$9,078**。
3. **PR 第一套也要缴 5% ABSD**，不是 0。公民第一套才是 0。这两行最容易串。

## 例 3 · 外国人买 $2,500,000 私宅

### 输入（用户原话）

> 「外国人客户，第一次在新加坡买房，250 万的私宅。40 岁，想贷 75%、25 年。他问总共要准备多少。」

名下未偿房贷 0 笔。国籍不属于 FTA 优待国（不是冰岛 / 列支敦士登 / 挪威 / 瑞士的国民或 PR，也不是美国国民）——**这一句必须先确认**，属于 FTA 优待国的话按公民待遇走，第一套 ABSD 是 0，差 150 万。

### 税率截至 2026-09-17 · 税率和规则会变，算完对一眼 IRAS 官网

### 表一：印花税

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| 税基 | 成交价 2,500,000（无估价 → 贷款基数同为 2,500,000） | 2,500,000 |
| BSD 第 1 档 | 180,000 × 1% | 1,800 |
| BSD 第 2 档 | 180,000 × 2% | 3,600 |
| BSD 第 3 档 | 640,000 × 3% | 19,200 |
| BSD 第 4 档 | 500,000 × 4% | 20,000 |
| BSD 第 5 档 | 剩余 2,500,000 − 1,500,000 = 1,000,000 × 5% | 50,000 |
| **BSD 小计** | 1,800 + 3,600 = 5,400；+19,200 = 24,600；+20,000 = 44,600；+50,000 = **94,600** | **94,600** |
| ABSD | 身份 FR · 任何一套 → 60%；2,500,000 × 60% | 1,500,000 |
| **印花税合计** | 94,600 + 1,500,000 | **1,594,600** |

分档宽度自检：180,000 + 180,000 + 640,000 + 500,000 + 1,000,000 = **2,500,000** ✓
速记对答案：累计到 $1,500,000 的 BSD 是 $44,600 ✓，再加顶上 100 万的 5% = $50,000 → $94,600 ✓
第 6 档（6%）没有用到：税基 2,500,000 < 3,000,000，5% 那档还没填满（只用了 100 万 / 150 万）。

### 表二：首付与贷款

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| LTV 判定 | 未偿房贷 0 笔；年限 25 ≤ 30 ✓；40 + 25 = 65，未超过 65 ✓ → **75%** | 75% |
| 贷款额 | 2,500,000 × 75% | 1,875,000 |
| 首付总额 | 2,500,000 − 1,875,000 | 625,000 |
| └ 最低现金部分 | 2,500,000 × 5% | 125,000 |
| └ 「可用 CPF OA 或现金」的部分 | 625,000 − 125,000 = 500,000，但**外国人不是 CPF 会员、没有 OA** → 这 500,000 也只能现金 | 500,000（全现金） |
| 印花税合计（不能贷款） | 表一 | 1,594,600 |
| **开工前要准备的现金** | 625,000 + 1,594,600 | **2,219,600** |

### 表三：月供与 TDSR

| 项 | 计算过程 | 结果 |
|---|---|---|
| 月数 n | 25 × 12 | 300 |
| 压力测试利率 | 住宅 4% | 4.00% |
| 月利率 i | 0.04 / 12 | 0.00333333 |
| (1+i)^300 | | 2.71376516 |
| i × (1+i)^300 | | 0.00904588 |
| 分子 | 1,875,000 × 0.00904588 | 16,961.03 |
| 分母 | 2.71376516 − 1 | 1.71376516 |
| **压力测试月供** | 16,961.03 / 1.71376516 | **S$9,896.94** |
| 参考月供（市场约 1.45%） | i = 0.0145/12，n = 300 | S$7,454.84 |
| 反推最低收入门槛 | 9,896.94 / 0.55 | **S$17,995 / 月** |
| TDSR 判定 | 客户未给月收入 → **待补：月总收入、现有每月债务** | 待补 |
| MSR | 私宅，不适用 | 不适用 |

收入没给就写「待补」，不填零、不猜。

### 一句话结论

外国人买 S$2,500,000 私宅：印花税合计 **S$1,594,600**（BSD 94,600 + ABSD 1,500,000），贷 S$1,875,000 / 25 年，首付 S$625,000（**外国人没有 CPF OA，这 62.5 万全是现金**），加上印花税，开工前现金约 **S$2,219,600**；压力测试月供约 **S$9,897**，按 TDSR 55% 反推月收入需 S$17,995 以上（他的收入待补）。

### 这个例子要特别说的三件事

1. **印花税等于房价的 63.8%。** 1,594,600 / 2,500,000 = 63.8%。ABSD 60% 是压倒性的那一项，跟房价高低没关系——外国人任何一套都是 60%。
2. **外国人的首付全是现金。** 表二那行「可用 CPF OA 或现金」对非 CPF 会员不成立，62.5 万首付 + 159.46 万印花税 = **222 万现金**，这是客户最容易低估的地方。
3. **先确认国籍。** 冰岛 / 列支敦士登 / 挪威 / 瑞士的国民及 PR、美国国民按新加坡公民待遇——第一套 ABSD 就是 0%，印花税从 159 万变成 9.46 万。这一句不问，整张表就是废的。

## 例 4 · 公民买第一套 HDB 转售 $800,000，估价只有 $760,000，收入里有佣金

### 输入（用户原话）

> 「客户新加坡公民夫妻，第一套房，HDB 转售，谈到 80 万，HDB 估价出来 76 万。他 35 岁，走银行贷款不走 HDB 贷款，想贷 25 年。收入他说月入 9 千——问了一下，底薪 5 千、佣金平均 4 千。名下没有任何房贷。」

四句话必须先确认，这个例子全部踩到：

- **估价 76 万 < 成交价 80 万** → 两个基数分开走，差额 4 万是 COV，必须全现金。
- **收入里有 4 千佣金** → 银行至少打 30% haircut，认可收入不是 9,000。
- **HDB** → MSR 30% 和 TDSR 55% 两个都要过，取更紧的。
- **未偿房贷 0 笔**（问过）→ LTV 75%。

### 税率截至 2026-09-17 · 税率和规则会变，算完对一眼 IRAS 官网

### 两个基数（这一段写在最前面，别让客户把两个数混了）

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| **税基**（BSD / ABSD 用） | max(800,000, 760,000) | **800,000** |
| **贷款基数**（LTV / 首付 / 最低现金用） | min(800,000, 760,000) | **760,000** |
| 估价缺口 COV | 800,000 − 760,000 | 40,000（**全现金，不能用 CPF，不计入 LTV**） |

### 表一：印花税

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| 税基 | max(成交价, 估价) = 800,000 | 800,000 |
| BSD 第 1 档 | 180,000 × 1% | 1,800 |
| BSD 第 2 档 | 180,000 × 2% | 3,600 |
| BSD 第 3 档 | 剩余 800,000 − 360,000 = 440,000 × 3% | 13,200 |
| **BSD 小计** | 1,800 + 3,600 = 5,400；+13,200 = **18,600** | **18,600** |
| ABSD | 身份 SC · 名下 0 套新加坡境内住宅 → 第 1 套 0% | 0 |
| **印花税合计** | 18,600 + 0 | **18,600** |

分档宽度自检：180,000 + 180,000 + 440,000 = **800,000** ✓
速记对答案：累计到 $360,000 的 BSD 是 $5,400 ✓，再加 44 万的 3% = $13,200 → $18,600 ✓

### 表二：首付与贷款（全部用贷款基数 760,000）

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| LTV 判定 | 未偿房贷 0 笔；年限 25 ≤ 25 年（HDB 的门槛是 25）✓；35 + 25 = 60 ≤ 65 ✓ → **不降档，75%** | 75% |
| 贷款额 | **760,000**（贷款基数）× 75% | 570,000 |
| 首付总额 | 成交价 800,000 − 570,000 | 230,000 |
| └ 最低现金部分 | 760,000 × 5% | 38,000 |
| └ 估价缺口 COV（全现金） | 800,000 − 760,000 | 40,000 |
| └ 可用 CPF OA 或现金 | 230,000 − 38,000 − 40,000 | 152,000 |
| 印花税合计（不能贷款） | 表一 | 18,600 |
| **开工前要准备的现金（最低口径）** | 38,000 + 40,000 + 18,600 | **96,600** |

**如果这里用错基数**（拿税基 800,000 去乘 LTV）：贷款会算成 600,000、首付算成 200,000、最低现金算成 40,000——贷款多算 3 万、首付少算 3 万，而银行只会放 57 万。客户按这张错表去准备钱，签约时差 3 万。

### 表三：月供与 TDSR / MSR

| 项 | 计算过程 | 结果 |
|---|---|---|
| 月数 n | 25 × 12 | 300 |
| 压力测试利率 | 住宅 4% | 4.00% |
| 月利率 i | 0.04 / 12 | 0.00333333 |
| (1+i)^300 | 工具求值，对因子表 ✓ | 2.71376516 |
| i × (1+i)^300 | | 0.00904588 |
| 分子 | 570,000 × 0.00904588 | 5,156.15 |
| 分母 | 2.71376516 − 1 | 1.71376516 |
| **压力测试月供** | 5,156.15 / 1.71376516 | **S$3,008.67** |
| **认可收入** | 固定 5,000 + 可变 4,000 × 70% = 5,000 + 2,800 | **7,800**（不是 9,000） |
| TDSR 额度 | 7,800 × 55% − 0 | 4,290 |
| TDSR 判定 | 3,008.67 ≤ 4,290 → 过 | 过 |
| MSR 额度（HDB 必算） | 7,800 × 30% − 0 | 2,340 |
| MSR 判定 | 3,008.67 > 2,340 → **不过，差 S$668.67 / 月** | **不过** |
| 瓶颈 | MSR 比 TDSR 紧，卡在 MSR | MSR |
| 反算最大可贷本金（M = 2,340） | 2,340 × 1.71376516 / 0.00904588 | **S$443,318** |
| 反推最低收入门槛（MSR 口径） | 3,008.67 / 0.30（**按全额固定工资算的下限**） | S$10,029 / 月 |

按 MSR 卡住的 443,318 重算一遍首付：

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| 贷款额（MSR 上限） | 反算 | 443,318 |
| 实际 LTV | 443,318 / 760,000 | 58.33%（没触到 75%） |
| 首付总额 | 800,000 − 443,318 | 356,682 |
| └ 最低现金 + COV | 38,000 + 40,000 | 78,000 |
| └ 可用 CPF OA 或现金 | 356,682 − 78,000 | 278,682 |
| **开工前要准备的现金（最低口径）** | 78,000 + 18,600 | **96,600** |

### 一句话结论

公民第一套买 S$800,000 HDB 转售（估价 S$760,000）：印花税合计 **S$18,600**（BSD 18,600 + ABSD 0）；贷款按估价算，75% 只有 S$570,000，首付 **S$230,000**（其中现金至少 S$38,000 + COV 全现金 S$40,000）；压力测试月供 S$3,008.67，TDSR 过但 **MSR 不过**（认可收入 7,800 × 30% = 2,340），按 MSR 最多贷 **S$443,318**。

### 这个例子要特别说的四件事

1. **两个基数方向相反。** 税按较高者（80 万）、贷款按较低者（76 万）。估价低于成交价的时候，两头都往坏方向走：税不减，贷款变少，差额全现金。
2. **佣金收入只认七成。** 客户嘴上是「月入 9 千」，银行算的是 7,800。MSR 额度从 2,700 掉到 2,340，最大可贷本金从 S$511,521 掉到 S$443,318——差 6.8 万，全靠这一句问出来。
3. **HDB 的瓶颈通常是 MSR 不是 TDSR。** 30% 比 55% 紧得多，私宅的经验直接搬过来一定算错。
4. **这是银行贷款，不是 HDB 贷款。** 走 HDB 自有贷款的口径不一样（利率下限 3%、MSR 是否同样 30% 本技能未核实），照 SKILL.md 那条规矩：不给数字，让他看 HLE 页面 / 申请 HLE。

## 例 5 · 外国人买 $2,500,000 商铺（非住宅）

### 输入（用户原话）

> 「外国人客户要买个商铺，250 万，问要交多少税、要准备多少钱。他 45 岁，月收入 3 万固定工资，banker 口头说能批七成、20 年。」

第一句话先分流：**这是非住宅**（商铺 / 办公 / 工业），不是住宅。按 SKILL.md 的「非住宅怎么走」切表：非住宅 BSD 表、**不缴 ABSD**、不走住宅 SSD、不看 MSR、压测 **5%**、贷款成数按银行政策（本技能不给数，这里用的是 banker 给的 70%）、CPF 不能用于非住宅。

### 税率截至 2026-09-17 · 税率和规则会变，算完对一眼 IRAS 官网

### 表一：印花税（**非住宅** BSD 表，顶档 5%）

| 项 | 计算过程 | 金额 S$ |
|---|---|---|
| 税基 | 成交价 2,500,000（无估价 → 贷款基数同为 2,500,000） | 2,500,000 |
| BSD 第 1 档 | 180,000 × 1% | 1,800 |
| BSD 第 2 档 | 180,000 × 2% | 3,600 |
| BSD 第 3 档 | 640,000 × 3% | 19,200 |
| BSD 第 4 档 | 500,000 × 4% | 20,000 |
| BSD 第 5 档（非住宅顶档 5%） | 剩余 2,500,000 − 1,500,000 = 1,000,000 × 5% | 50,000 |
| **BSD 小计** | 1,800 + 3,600 = 5,400；+19,200 = 24,600；+20,000 = 44,600；+50,000 = **94,600** | **94,600** |
| ABSD | **非住宅不缴** | **0** |
| **印花税合计** | 94,600 + 0 | **94,600** |

分档宽度自检：180,000 + 180,000 + 640,000 + 500,000 + 1,000,000 = **2,500,000** ✓
**走错表的代价**：照住宅表给外国人套 60% ABSD，会凭空造出 **S$1,500,000** 的税——把一笔 9.46 万的交易说成 159 万。这是本技能最贵的一种错（红线 10）。
（250 万这个价位上，非住宅 BSD 和住宅 BSD 都是 94,600；两张表要到 300 万以上才分岔——住宅顶档 6%、非住宅 5%。别因为这里数字一样就以为两张表通用。）

### 表二：首付与贷款

| 项 | 计算过程 | 金额 S$ |
|---|---|---|

| 印花税合计（不能贷款） | 表一 | 94,600 |
| **开工前要准备的现金（最低口径）** | 750,000 + 94,600 | **844,600** |
| GST | 卖方是 GST 注册人时可能另有一笔。**本技能不算、不给税率** → 问律师 / 看 IRAS GST 页 | 不算 |

### 表三：月供与 TDSR（非住宅压测 5%，不看 MSR）

| 项 | 计算过程 | 结果 |
|---|---|---|
| 月数 n | 20 × 12 | 240 |

### 一句话结论

外国人买 S$2,500,000 商铺（非住宅）：印花税合计 **S$94,600**（非住宅 BSD 94,600 + ABSD **不缴**），按 banker 给的七成贷 S$1,750,000 / 20 年，首付 **S$750,000 全现金**（非住宅不能用 CPF），加印花税，开工前现金约 **S$844,600**；压测 5% 的月供约 S$11,549，TDSR 过。**GST 和最低现金首付比例不在本速算范围，问律师和 banker。**

### 这个例子要特别说的三件事

1. **ABSD 是住宅税。** 商铺、办公室、厂房、仓库都不缴。中介最容易在这里出事——把住宅那套直接搬过来，一句话报错 150 万。
2. **非住宅的贷款成数没有官方上限可抄。** MAS 的 75/45/35 是住宅口径。拿不到 banker 的数就把这几行写「待补」，不要用 75% 顶上去。
3. **非住宅压测是 5%，不是 4%。** 而且 5% 的复利因子速查表里没有，必须用工具算（红线 9）。
