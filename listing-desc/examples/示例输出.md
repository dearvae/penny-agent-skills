# 示例输出：一份房源资料 → 一整套挂牌文案

> **这一整页的项目名、门牌、报价、面积、装修年份全是编的**，只用来演示格式和纪律，别照抄任何数字。
> Eastbourne Grove 不是真实项目。落款那几行的姓名、CEA 注册号、经纪行执照号、电话是**占位符**（全 0），
> 用的时候换成你自己的，不要照抄。


## 第 0 步之前：先确认归属

> 先确认一件事：**这套房是你自己在挂的吗？**（你或你所属经纪行拿到业主 / 房东的书面授权）
> 是 → 我直接给你可以粘贴的几版文案。
> 不是 → 我只给你「要问业主哪几项」的收料清单和一份骨架，不出可粘贴正文。

他回：

```
我自己的盘，业主上周签了授权给我
```

→ 走 A 线。（下一套房再问一次，这个答案不往下带。）

## 第 0 步：缺的一次问齐

> 这几项我这里是空的，你补一下我就开始写（不知道的写「不知道」，我就整篇不提它）：
> 1. 1 公里内那两所小学叫什么、各多远、在哪量的？
> 2. 1,109 sqft 的三房我不猜有没有 utility room 和阳台，实际有哪些？
> 3. Kembangan 的**线路代号**和 **District 编号**：你资料里写了 D14，代号（EW 几）你手上有吗？没有我就只写站名——我不联网，不凭记忆填。
> 4. 业主那句「晚上很安静，房间朝里」我想写成引述。**你问过他同不同意把这句写进公开挂牌文案吗？**哪天问的？
> 5. 「可以谈一点」要不要写进 description？（写 negotiable 会招砍价，但也会多来问的人，你决定）
> 6. 这段要发哪几个渠道？要发自己网站 / 小红书 / 客户群的话，把你的姓名、CEA 注册号、经纪行名称、经纪行 licence number、CEA 登记电话给我。

他回：

```
1. 还没查，你先别写学校
2. 有一个 utility room，没有女佣房，一个阳台
3. 代号我不确定，你别写，站名就够了。D14 是我从挂盘资料上抄的，没错
4. 问过了，昨天 2026-09-16 他说可以写，只要别提他名字
5. 不要写 negotiable
6. PropertyGuru + 99.co，我自己网站也放一版。姓名和 CEA 那几项我发你
```

先算 psf：`1,880,000 ÷ 1,109 = S$1,695 psf`（四舍五入到整数）。
挂 2 个平台，所以标准版出 **A（PG）/ B（99.co）** 两个，事实逐条一致。

## 3. 还缺的 / 要你确认的

1. **1 公里内的小学** —— 你说有两所但名字要查。**所有版本里我一个字都没写学校**。你去 OneMap 量过、拿到学校名和距离，我加进 LOCATION 段，写法是 `within 1 km of {学校名} Primary School`，不会写「学区」两个字。
2. **Kembangan 的 MRT 线路代号** —— 你说不确定，所以**四版正文都只写站名，没写代号**。我不联网，凭记忆填一个代号就是往广告里塞一条没出处的事实，填错就是误导买家。你从挂盘后台或项目页上抄到了发我，我加回括号里。
3. **TOP 2016 / 99 年地契 / D14 / 设施清单** —— 全部按你给的资料抄的，**不是我查的**（我不联网）。你手上的资料要是本身抄错了，文案就跟着错——挂之前自己对一眼 PropertyGuru 项目页。
4. **`negotiable`** —— 按你说的没写。以后想加，就加在收尾那句，不要加在 HOOK。
5. **物业费（maintenance fee）** —— 资料里没有。买家会问，但这是钱的数字，我不替你估。你拿到实际金额，要写就写进正文最后一行并注明是每月每户；不想写就留着口头答。
6. **业主的引述** —— 你说 2026-09-16 问过、他同意公开、只要别提名字。所以正文里他只以 `the owner` / 「业主」出现：**没有姓名、没有性别（he / she / 他）、没有「自己住的」「要搬走」「家具带走」这些处境**。原稿里我写过「the owner lived in himself」「He is taking his furniture with him」，都删了——广告带着地址，那些是能指到具体一个人的个人资料。单元本身的状态（`unfurnished`、`vacant possession`）照写，那是房子的事，不是业主的事。
7. **女佣房** —— 你说没有，所以整篇没提。挂牌页的勾选栏位记得也别勾。
8. **单元号和楼层数** —— 全篇没有，只有 `mid floor`。这是刻意的，别自己加回去。
9. **落款那四项** —— 长版和长版·中文里现在是占位符（全 0）。把你真实的姓名、Salesperson Registration No.、经纪行名称、Estate Agent Licence No.、CEA 登记电话发我，我替换掉；不替换就别发出去。PG 和 99.co 那两版不需要这一段（平台自己会印）。
