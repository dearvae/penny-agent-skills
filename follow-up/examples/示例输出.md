# follow-up 示例输出

两个完整例子，都是「用户说了什么 → skill 出什么」的原样记录。
日期按 2026-09-17 那天跑的。客户一律写成 C 先生 / C 小姐，不落任何真实资料。

---

## 这台机器上的口气档案（两个例子都按它写）

`我的档案/跟进口气.md` 的「抽出来的特征」节（第 0 步从他贴的两条消息里抽的——他贴之前已按第 0 步把名字、单元号、项目名、金额换成占位符，抽完特征那两条原话就删了，档案里只剩下面这张表）：

| 项 | 他的习惯 |
|---|---|
| 语言 | 英文为主；客户用中文来他就用中文回，句式一样短 |
| 称呼 | `Hi <名>` / 中文就 `<姓>姐`、`<姓>哥` |
| 自称 | 不自称（老客户都知道他是谁） |
| 长短 | 2–4 句，一句十来个字，不分段 |
| 开头 | 直接说事，不寒暄，不说 Sorry to disturb |
| 结尾 | `Thanks` 或 `Let me know`；中文用「有问题随时问我」 |
| emoji | 不用 |
| 标点 | 句号少，习惯用空格断开两句 |
| 他不会说的话 | 不用感叹号；不说 dear；不说「机会难得」「抓紧」 |

# 例 1 · 看过房没表态（S2）

## 用户说

> @follow-up 帮我跟进一下周日看房那个客户。他看了 Queenstown 两套三房，看完说 "ok we discuss and let you know"，到今天四天没消息了。他老婆当场问过 maintenance fee 多少，我当时没答上来。

## skill 先问了一句

> 两件事确认一下：
> 1. maintenance fee 你后来查到了吗？查到多少、从哪问来的？——草稿 A 要拿这个当理由，查不到我就不写这条。
> 2. 他们是自住吧？（决定我要不要提租约状态）
>
> 另外提醒一句节奏：S2 阶段第一条最好在看房后 24–48 小时内发，现在第 4 天了，已经晚两天。今天就发，别再等。

## 用户回

> 查到了，S$385 一个月，挂盘那个中介帮我问的管理处，昨天回我的。自住，两个小孩。

## skill 输出

````
客户：C 先生 · 阶段：S2 体验过没表态（看过房没表态）· 第 1 次跟进 · 距上次 4 天
他在想什么：有点兴趣但还没到要决定，正在跟太太算数；也可能已经否掉了，只是不好直接说。
这次要拿到的：一个明确的反馈，好还是不好都行。

──────── 草稿 A · 给理由 ────────
```
Hi C, the maintenance fee for that unit is S$385 a month — the listing agent checked with the management office.
Your wife asked on Sunday so I didn't want to guess.
Thanks
```

为什么这么写：他太太当场问过、我当场没答上来，这是最干净的回访理由——不是找他，是补上答案。全条没有一个问题，不给回复压力。
用到的新信息：该单位管理费 S$385 / 月 ｜ 出处：挂盘中介向管理处查证后回复 ｜ 截至：2026-09-16
（发之前跟中介对一眼数字有没有变；这是他给你的口径，不是官方文件。）

──────── 草稿 B · 给台阶 ────────
```
Hi C, no rush on this one.
If the timing has shifted I'll just hold off and you can come back to me whenever you're ready.
```

为什么这么写：这条的作用是把主动权还给他。全条没有问号，明确说「不回就是先放着」——他不回也不用尴尬，下次要找你时不会觉得欠你一个答复。

──────── 草稿 C · 给行动 ────────
```
Hi C, one quick question so I know what to keep an eye out for — are you still set on a 3-bedder, or can I include 3+1 layouts?
A yes or no is enough.
```

为什么这么写：只问一件事，十秒能回。答案两个方向都有用：说 3-bedder 就继续筛，说可以 3+1 就等于他还在看。回什么都不算逼他表态。
请求是：是非题

────────────────────────────
挑一条发，别三条都发。
下一次跟进：2026-09-24 – 09-26 ｜ 再没回：10 月初第 3 次，之后停，转季度问候
自检：☑ 没有未标出处的数字  ☑ 草稿里每个关于房子的说法都能指回他给的那句话（只有管理费，是他给的）  ☑ 无 CEA 禁语  ☑ 没有逼单话术  ☑ 长度和他平时一样（2–3 句、不用 emoji）  ☑ 称呼对  ☑ 没替客户做决定
````

**这次学到的（追加进 `我的档案/跟进口气.md` 的「他改过的措辞」节）：**
他选了草稿 A，把 `so I didn't want to guess` 改成 `so here you go`。→ 他不爱写解释自己的那半句，以后直接给信息就收尾。

# 例 2 · 嫌贵（S4）

## 用户说

> @follow-up 客户嫌贵。她要 Tiong Bahru 两房，预算 4,200 一个月，她看中的那套房东坚持 4,800。她三天前跟我说「太贵了 lah，这个价我不如去 Redhill」。这是这件事的第一次跟进，她之后没再提。同一栋楼低层有一套两房刚挂 4,300，我今天在 PG 看到的。

## skill 输出

````
客户：C 小姐 · 阶段：S4 嫌贵（租盘，预算不够型）· 第 1 次跟进 · 距上次 3 天
他在想什么：不是觉得那套不值，是这个数字她给不起，而且她已经想好了退路（Redhill）。
这次要拿到的：把「预算」和「地段」分开来谈——她的预算在 Tiong Bahru 还有没有东西，是可以用事实回答的。

──────── 草稿 A · 给理由 ────────
```
C 姐 同一栋楼低层有一套两房今天挂出来 4,300
比你看的那套低一点 楼层低
挂牌价 房东那边还没谈过 面积和图我一起发你看看
```

为什么这么写：她的问题是数字，那就给她一个新的数字，不是给她说服。明说「还没谈过」，不暗示能砍到 4,200——不承诺任何我说不了算的事。**没写「面积差不多」**：用户给的是价格、楼层、同一栋楼，没给面积；同一栋楼不同 stack 的两房能差十几平米，所以改成「面积和图我一起发你」，把核对挪回他手上（红线 2）。
用到的新信息：同项目低层两房新挂盘 S$4,300 / 月 ｜ 出处：PropertyGuru 在挂房源（学员本人 2026-09-17 自己搜到的）｜ 截至：2026-09-17
（这是**挂牌价，不是成交价**，草稿里已经写明。发之前刷一眼那条挂盘还在不在、价格有没有改。）

──────── 草稿 B · 给台阶 ────────
```
C 姐 4,800 这个数字如果不合适 我们就按 4,200 找 不用勉强
Tiong Bahru 这个预算的房源不多 但有就发你 你不回我也不会一直催你
```

为什么这么写：她说「太贵了」之后最怕的是被追着劝。这条直接承认她的预算是条件、不是障碍，并说明不催——把她从「要不要回中介」这件事里放出来。没有问号。

──────── 草稿 C · 给行动 ────────
```
C 姐 一个问题 4,300 那套要不要我帮你约看一下
要就回我一句 我去问时间 不要也直接说 我继续找
```

为什么这么写：一个是非题，回哪个都推进：要看 = 预算和地段都还在，不看 = 她大概真的转去 Redhill 了，这次跟进也算有结果。没有给她第二个问题，也没有问她「预算还能不能加」——那是逼单的另一种写法。
请求是：是非题

────────────────────────────
挑一条发，别三条都发。
下一次跟进：2026-09-24 前后（S4 第二次隔一周）｜ 再没回：10 月中第 3 次，之后停，有符合 4,200 的新盘再联系
自检：☑ 数字都标了出处和截至日期，且写明是挂牌价  ☑ 草稿里每个关于房子的说法都能指回她给的那句话（价格、楼层、同一栋楼；面积没给所以没写）  ☑ 无 CEA 禁语（没写「这个区最便宜」「保值」）  ☑ 没有逼单话术（没写「房东在跟别人谈」）  ☑ 没有暗示能降价  ☑ 中文、短句、不用 emoji，符合档案  ☑ 没拿别人的成交价压她
````

**为什么没写这些（写了就踩红线）：**
- 「这个价在 Tiong Bahru 已经很便宜了」→ 没有她认的出处，属于替她判断值不值。
- 「上个月同栋成交 4,700」→ 学员没查到官方成交记录，不能凭印象写；真要写，数字得来自他自己查到的官方来源并标出处和截至日期。
- 「房东说这周有人要签」→ 制造时间压力，不写。
- 「不然你加 200 试试」→ 劝加钱，S4 阶段的禁区。
- 「Tiong Bahru 这个价已经是最便宜的了」→ 绝对化用语，CEA 广告规矩的雷（红线 8），有没有出处都不写。
- 「这一带长期保值」→ 收益承诺。它既没有数字（红线 2 管不到）、也不是「我建议你租」（红线 7 管不到），归红线 8 管。
- 「面积差不多」→ 她给的是价格、楼层、同一栋楼，没给面积。房源属性和数字同一条待遇（红线 2），编不得。
