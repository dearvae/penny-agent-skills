# 发布平台规范 · 视频号 vs 小红书（出片前必读）

四个视频 skill（agent-shot / agent-cut / newlaunch-shot / news-shot）各存一份，改一处要同步。
⚠️ **这一份已经先改了，另外三份还是旧版**：新增的第 1.5 节（房源广告片 vs 小红书的 CEA 冲突）、
第 1 节的音乐授权那一格、第 4 节自检表的三处改动，还没同步过去。下次动那三个 skill 时一起搬。

## 0. 先问平台

用户没说发哪里，**出片前先问一句**：「发微信视频号、小红书，还是两个都发？」两个都发就按两套规矩各出一版
（差别主要在片尾联系方式、封面文字、发布文案），不要用一版硬发两边。

## 1. 两个平台的差别（决定片子怎么改）

| | 微信视频号 | 小红书 |
|---|---|---|
| 片尾联系方式 | 可以放微信号 / 电话文字；**不放二维码**（带码画面常被限流） | **画面、字幕、文案、评论都不出现微信号、电话、「VX」「加V」「私」、二维码**——这是小红书最常见的限流和封号原因。落款只留姓名 + 经纪行，联系方式写「主页」 |
| 封面 | 大标题说观众关心的事；别用夸张标题党、惊叹号堆叠 | 同左；封面尺寸 3:4（1080×1440），文字别贴边 |
| 标题 / 文案 | 短、带钩子；可带公众号引导 | 带可搜索词（新加坡 / 租房 / 留学 / 地铁站名）；#话题 3–6 个；**不写任何联系方式** |
| 外站痕迹 | 不带抖音 / 小红书水印和 logo | 不带抖音 / 视频号水印和 logo；搬运痕迹会被判非原创 |
| 音乐 | 用在**这个平台**有授权的曲子。**引擎内置那 10 首不算**——它们来自剪映曲库，授权范围只到剪映 / 抖音（见 `pipeline.md` 第 1 节） | 同左 |
| 内容质量 | 纯硬广（整条都在推销）会被压流量 | 同左，更严：先给价值再带一句服务 |

## 1.5 ⚠️ 单盘 / 房源广告片和小红书是真冲突，别拿自检表当绿灯

CEA 对 **property advertisement** 的要求（cea.gov.sg「Check if your property agent is registered」，
截至 2026-09）是：**经纪姓名 + CEA 注册号 + 电话 + 经纪行名称 + 经纪行牌照号**，五项都要写上；
唯一的例外是报纸分类广告和短信广告（那两种只要姓名 + 电话）。社媒和门户不在例外里。
小红书这边又明文不许联系方式上屏。**两边同时满足做不到。**

所以碰到**单盘 / 房源广告片**（SKILL.md 第 1b 节那条线，或任何报具体价格面积在推一套在挂房源的片子）：

- **默认建议：不要发小红书。** 单盘片发视频号（可以放电话文字），小红书只发不指向具体房源的科普内容。
- 他坚持要发小红书：把这个取舍原话说给他——「电话上不了屏，CEA 那条就缺一项；
  要发就是你自己在承担这个判断」。他点头才做，并把这句写进 `发布物料.md` 留痕。
- 别做的事：**别把「小红书版没有电话」当合规项打勾**。那一勾只说明平台规矩过了，CEA 那条恰恰没过。

非广告的科普 / 新闻 / 算账片不受这条影响——那些不是 property advertisement。

## 2. 两边都禁的内容（写稿时就不写，不是事后改）

- **收益承诺、投资引导**：「稳赚」「保值」「肯定涨」「回报 X%」「建议买」——广告法 + 平台金融类风控 + CEA 广告规矩三重雷。算账片只说「这套房的账是这样」
- **绝对化用语**：「最」「第一」「唯一」「顶级」「全新加坡最好」——广告法禁用词，写成具体数字或「之一」
- **学区房**：只能说「在 X 小学 1 公里内」
- **金融敏感词**：「垫资」「首付分期」「零首付」「贷款包过」——触发平台金融风控
- **别人的脸、别人的房、别人的客户资料**：不脱敏不上屏；房源实拍只用自己有权用的素材
- **煽动、对立、政治时政评论**：新闻快讯只陈述政策和数字，不评论政府、不站队
- **未核实的数字和「据说」**：会被判不实信息，也砸自己招牌

## 3. 出片时按平台自动做的事

1. 落款卡 `signoff.contact`：小红书版留空或写「联系方式见主页」；视频号版可写微信号
2. 封面：小红书版出 1080×1440，视频号版出 1080×1920；文字都过一遍禁用词
3. 字幕和口播：禁用词表过一遍（收益承诺 / 绝对化 / 学区房 / 金融敏感词），有就改稿，不是加提醒
4. 发布物料分两栏：视频号（标题 + 文案 + 话题）、小红书（标题 + 正文 + 话题，无联系方式）
5. 交付时附「平台自检」清单，写明这条片针对哪个平台改了什么

## 4. 交付里的「平台自检」（照抄进发布物料）

- ☐ 平台：视频号 / 小红书 / 两版
- ☐ 片型：单盘 / 房源广告片 → 先过第 1.5 节；非广告的科普 / 新闻 / 算账 → 跳过第 1.5 节
- ☐ 联系方式：小红书版画面和文案里没有微信号、电话、二维码
- ☐ 这是单盘 / 房源广告片的话：落款带齐**姓名 + CEA 注册号 + 电话 + 经纪行 + 经纪行牌照号**；
  发小红书导致电话上不了屏的，第 1.5 节那句取舍已经跟他说过、并写进了 `发布物料.md`
- ☐ 禁用词：收益承诺、绝对化、学区房、金融敏感词，全片 0 个
- ☐ 水印：没有别的平台 logo
- ☐ 音乐：用的曲子**在这个目标平台有授权**（引擎内置的剪映曲库那 10 首不算），或者这条片 `"music": false`
- ☐ 不是整条硬广：前 80% 是内容，最后一句才是服务
