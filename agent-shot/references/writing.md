# 调研与写稿 · 事实纪律 + 白话红线

## 调研与核实（每条片都过，不可跳）

用 WebSearch/WebFetch 做三件事：找一手来源（官方文告/公司通稿）、看别家怎么报（常能挖到
截图里没有的加分数字）、看网友讨论（争议点是钩子和互动问题的原料）。据此**重写角度**，
不要照抄来料的叙述顺序。

**可信度分级，只有前两级能上屏：**

| 级别 | 来源 | 能不能上屏 |
|---|---|---|
| A | 政府官网（URA / HDB / MND / LTA / MAS / CEA）、公司官方通稿、开发商官网 | 能 |
| A | 用户本人提供且他确认公开的数字（他的成交、他的房） | 能，物料里注明「以你提供为准」 |
| B | 主流财经媒体（The Edge、Business Times、EdgeProp）**且能看到发布日期** | 能，口播里带来源 |
| C | SEO 内容站、AI 摘要、论坛帖、同行朋友圈 | **不能** |

SEO 站会互相打架（同一项目三家给三套户型、两个邮编都是实测遇过的），一个都别信。
政策类背景查官网原文，别转述第三方解读。

核实完在脚本 md 里留**数字核对表**：每个上屏数字 → 出处链接 → 级别。核不到的删掉。

## 写稿要点

- **白话到「聪明的 12 岁孩子能复述」**：不用「文告/试行/毗邻/产品线」这类书面词
  （说「说/开始试/旁边是/一房到五房都有」）。本机装了 `ljg-plain` skill 就调用它；
  没装就按这条原则自己把关。
- **总长 45–75 秒**。字数用档案里**他的实测语速**算（比如 227 字/分 → 60 秒片写 220 字左右），
  别套别人的语速。8–14 段，一段一个意思，**一句 ≤15 字**。
- **开头 3 秒给一个具体、可验证的钩子**（几个硬事实堆在一起），
  不要「今天给大家讲讲」。结尾落到他的客群关心的行动上（「想看细节私我」），不落到「买」。
- **中性口语，不套任何现成博主的指纹**。他的口头禅从他自己的语音样本里听；
  听不出来就不端着、不书面、不硬造人设。
- 数字正文用阿拉伯数字（字幕好看），配音引擎自动转中文读法。

## CEA 禁语（一条都不许出现）

- 「稳赚」「保值增值」「肯定涨」「回报 X%」——任何收益承诺
- 「最后几套」「限时」——除非用户书面确认属实
- 「学区房」——只能说「在 X 小学 1 公里内」（新加坡是优先抽签不是划片直升）
- 自己算的价格/psf/租金回报当事实说——他没确认的数不上屏

## 多音字自检（写完必过，返工最贵的一类错）

MiniMax 念多音字会挑错读音，而 whisper 反听查不出来（转写是同一个字，CER 显示 0%）。
`ttsText` 救不了单字多音，唯一可靠的办法是**换词**。逐段扫：

| 高危字 | 会读错成 | 换成 |
|---|---|---|
| **得** děi（必须） | dé | 要 / 才能 |
| **还** hái（尚未） | huán | 删掉，或「目前」「暂时」 |
| **挨** āi（紧邻） | ái | 旁边是 / 靠着 |
| **长** cháng | zhǎng | 「全长」→「一共」 |
| **重** chóng（再次） | zhòng | 「重来」→「再来一次」 |
| **落** là（遗漏） | luò | 「落下」→「漏掉」 |
| **数** shǔ（点数） | shù | 「数一数」→「点一下」 |
| **行** háng（行业） | xíng | 「这一行」→「这个行业」 |
| **好** hào（喜好） | hǎo | 直接换动词 |
| **干** gàn（做） | gān | 「干这行」→「做这个」 |
| **为** wèi | wéi | 「别为它」→「别给它」 |

另两类漏网的：

- **cn2an 把「N 年」当年份读**：「12 年没有新盘」→「一二年」。凡「X 年」表**时长**，
  那段加 `ttsText` 写中文数词（「十二年」）。「2030 年代」也要 `ttsText`（「二零三零年代」）。
- **声调撞车**：「先在…」听成「现在…」、「私我」听成「死我」。写完在脑子里念一遍，
  有歧义就换语序（「榜鹅先试」）。这类只能靠反听 CER 和耳朵抓，每段的 CER 都要看。
