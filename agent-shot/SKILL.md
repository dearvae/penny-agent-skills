# agent-shot · 通用中介出片（可分发）

这条 skill 是「给不是 Penny 的人出片」的通用线：装到学员/客户自己的机器上用，
或者由 Penny 替客户跑。成片挂的是**档案里那个人**的脸、声音和 CEA 注册号——
出了事是他担责，所以第 0 步永远是确认档案齐不齐，事实纪律永远从严。

工作目录：装机时约定的目录（本机是 `/Users/beiningli/Desktop/自媒体`）。
环境没装过？先按 `references/setup.md` 走一遍装机清单。

产物目录约定：
- `remotion-edit/public/newlaunch/<YYYY-MM-DD>-<slug>/` — script.json、shots/、vo/、captions/、manifest.json、cover.png（目录名叫 newlaunch 是历史原因，这条「非 Penny」渲染线的所有片型都放这里）
- `成片/<YYYY-MM-DD>-<slug>/` — 成片 mp4、`封面/`、发布物料.md
- `references/profiles/<代号>/` — 用户档案 + 他的原始素材（形象照、声音样本）

---

## 0. 每次先查档案（这一步是本 skill 的灵魂，不许跳）

档案在 `references/profiles/<代号>/profile.md`。每次被调用：

1. **只有一份档案** → 默认就是他，直接往下走。
2. **有多份档案** → 问一句这条片是给谁出的。
3. **一份都没有** → 这是首次使用，**先建档再出片**。读 `references/onboarding.md`，
   把要收的东西**一次性列全**发给用户（别挤牙膏一样一条一条问），能收多少收多少，
   记录进档案，再继续。
4. **档案在但字段缺** → 只问缺的那几样。他之前明确拒绝过的（比如不挂 CEA 号）不算缺，
   但正式对外发布的片子要再确认一次口径还成立。

| 素材 | 用来干嘛 | 缺了怎么办 |
|---|---|---|
| 上屏姓名（他自己定的写法） | 落款卡 + 封面 | 必问 |
| 形象照（正面半身、背景干净） | 片尾落款卡头像 + 封面右下抠图 | 必问。实在没有：出片可以，但没有落款卡和带脸封面，要跟他说清楚这版是残的 |
| 声音样本 ≥15 秒 | 克隆声口播（本地或云端都要它） | 必问。急着看效果可先用 MiniMax 现成音色出 demo 版，正式版必须等克隆完 |
| CEA 注册号 + 经纪行（含牌照号） | 片尾合规落款 | 建档时收录 + 提醒一句「正式营销物料按新加坡规矩要挂」。**只提醒不代加**：他说要挂才挂进片子 |
| 配音路线（本地 F5-TTS / MiniMax 云端） | 决定配音怎么跑 | 建档时问一次，两条路线的取舍见 `references/pipeline.md` 第 2 节。想先看效果再注册账号的，先走本地 |
| 联系方式（微信/电话） | 片尾引流 | 可选 |
| 客群定位（HDB/私宅、租/买、留学生/本地家庭） | 判断选题对他有没有用、落点怎么写 | 建档时问一次 |

**为什么这么较真：** 这些素材是编不出来的——没照片就渲不出落款卡，假装有只会报错或出一张空卡；
音色 ID 是克隆出来的不是猜出来的。问一次、存进档案，以后每条片都不用再问，这笔账很划算。
同理，**出片过程中任何时候发现缺了只有他能给的东西（一个数字、一张图、一句确认），停下来问，
不要替他编**。

## 1. 判断片型（只接这三类）

| 片型 | 例子 | 要他给什么 |
|---|---|---|
| 政策 / 新闻快讯 | 印花税调整、新盘开售、URA 数据 | 一条新闻（截图/链接/原文）就够 |
| 算账 / 对比 | 3900 vs 4200 怎么选、回报率拆账 | 一张表：对比对象、拆项、结论数字，外加「愿不愿公开这套房的真实数字」 |
| 常识科普口播 | 押金不是解约金、地契年限、验房清单 | 他常被问的问题 + 他自己踩过的坑（有细节才有人看） |

**房源实拍 / 探房 / 人设日常不接**——那要逐条看他的原始素材、编时间码、核穿帮，
是外包剪辑不是出片。婉拒并说明可以给拍摄清单和模板。新盘 e-book 出片是另一条线（newlaunch-shot）。

---

## 2. 调研核实（不可跳过）

每个要上屏的数字都要有一手出处。可信度分级、来源坑、数字核对表的做法见
`references/writing.md` 的「调研与核实」节。核不到的数字删掉，不许估。

## 3. 写稿

按 `references/writing.md` 写：白话（聪明的 12 岁孩子能复述）、总长 45–75 秒、
一句 ≤15 字、**中性口语**（别套任何现成博主的语言指纹——他的口头禅从他自己的语音样本里听，
听不出来就写中性）、CEA 禁语一条不碰、多音字自检必过。
写完存 `脚本/NN_主题_脚本.md`（逐段口播 + 数字核对表 + 多音字自检记录）。

## 4. 配音 + 渲染

按 `references/pipeline.md` 走：script.json → 克隆声 TTS（按档案里的配音路线：本地 F5-TTS
或 MiniMax 云端，坑都写在那个文件里）→ Remotion 渲染 → 抽帧自查。
落款卡用档案里的姓名/头像；**CEA 号只在他确认要挂时才加**。

走 MiniMax 的要**逐段核语速**：短句多的段会随机拉长节奏，同段重跑能差 25%。
偏慢的段同参数重摇留最快的一条（别用 `--speed` 补），仍不达标用 `atempo ≤1.12` +
字幕时间轴同比缩放。合格带用**该中介本人**的实测语速 ±10%。完整流程见 `news-shot/SKILL.md` 第 6 步。

## 5. 封面

按 `references/pipeline.md` 的「封面」节：满幅底图 + 大标题 + 右下他本人抠图 + 姓名胶囊。
**不要用设计C**（那是 Penny 新闻号的版式，橙色胶囊写着「新加坡新闻快讯」，挂到别人号上是错的）。
渲染后必须看图检查文字有没有撞人像。出两版：1080×1920、1080×1440。

## 6. 交付（不代发）

发成片 + 两版封面，外加 `成片/<slug>/发布物料.md`：

1. 视频号/朋友圈标题 2–3 个 + 文案 + #话题
2. 小红书标题 2–3 个 + 正文 + #话题
3. 逐段口播全文（他可能想自己重录）
4. 数字核对表：每个上屏数字 → 出处链接 → 可信级别
5. 提醒三句：时效词（「昨天/今天」）只在当天发才准；网图版权他最终把关；
   挂了 CEA 号的，号码和经纪行是他给的，发之前自己再核一遍；没挂的，
   再提醒一句正式发布按规矩要挂——挂不挂始终是他的决定

发布全部由他自己来。不代发。

## 红线（不分片型，条条适用）

**红线的用法是提醒，不是代改。** 发现踩线（比如片子没挂 CEA 号、他给的数字像投资建议）
就停下来指出来，怎么处理由他决定——不要自作主张替他把合规元素加进视频。
唯一例外是你自己写的稿子：禁语在写的时候就不要写进去，那是作者的责任不是替用户改。

- **收益承诺一个字不许有**：「稳赚」「保值增值」「肯定涨」「回报 X%」全是 CEA 广告规矩的雷。
  算账片的措辞只能是「这套房的账是这样」，不能是「建议你买」。
- **法规讲错一次比不发还糟**：租约、印花税、地契这类内容，每条留一句来源。
- **「学区房」不许说**：新加坡是 1 公里内优先抽签，只能说「在 X 小学 1 公里内」。
- **声音克隆必须本人授权**：建档时问清楚，记录在档案里。
- **他给的数字要他确认**：成交价、租金这类他报的数，交付物料里注明「以你提供的数字为准」。
