# agent-shot · 通用中介出片（可分发）

这条 skill 是「给不是 Penny 的人出片」的通用线：装到学员/客户自己的机器上用，
或者由 Penny 替客户跑。成片挂的是**档案里那个人**的脸和声音（他要挂的话还有 CEA 注册号）——
出了事是他担责，所以第 0 步永远是确认档案齐不齐，事实纪律永远从严。

## 前提（每次开工先核对，缺「必须」就停下来先补，不要往下跑）

| | 项目 | 怎么确认 |
|---|---|---|
| 必须 | 装机 prompt 已跑通（Node、ffmpeg、poppler、whisper-cpp + 模型、Remotion 预装） | 学员装机时看到过「✅ 体检通过」；跑 `ffmpeg -version`、`npx remotion versions` 能出版本号 |
| 必须 | 出片引擎已装：`remotion-edit/`（`npm install` 过）+ `news-pipeline/`（venv 建好） | `remotion-edit/node_modules` 存在；`news-pipeline/.venv-tts/bin/python` 存在 |
| 必须 | 克隆声（二选一）：MiniMax 云端 voice_id 写在 `news-pipeline/.env.minimax`（key 以 `sk-api-` 开头），或本地 F5 参考音 `ref.wav` + `ref.txt` | 档案「音色 ID」一栏有值；合成一句测试能出声 |
| 必须 | 档案：上屏姓名、形象照、视觉风格 | `references/profiles/<代号>/profile.md` 存在且这三项不为空 |
| 可选 | CEA 注册号 + 经纪行、联系方式 | 没有就落款不挂，不追问 |
| 可选 | 数字人（HeyGen，学员自己的账号和 API key，配在他电脑的 `news-pipeline/.env.heygen`） | 没配就纯画面 + 克隆声出片；配了才在开头结尾加数字人段（`references/onboarding.md` 第 8 节、`pipeline.md` 2d） |
| 可选 | 学员自己加的 BGM | 没有就用内置 43 首（`public/music/bgm/README.md`） |
| 可选 | 参考片（他喜欢的别人的视频，或他自己以前发过的） | 有就按第 2c 步学它的配色、字体、字幕、动画；没有就用档案里的风格 |
| 可选 | 图库 key：`news-pipeline/.env.images` 里的 `PEXELS_API_KEY` / `UNSPLASH_ACCESS_KEY` | 没有也能搜（Wikimedia Commons + Openverse 免 key），有了图更多 |

## 发布平台（出片前先问，按平台改片子）

用户没说发**微信视频号**还是**小红书**（或两个都发），先问一句再动手。两平台的规矩不同，最要紧的：小红书的画面、字幕、文案里**不能出现微信号 / 电话 / 二维码**，视频号可以放文字联系方式但不放二维码；收益承诺、绝对化用语、学区房、金融敏感词两边都禁，写稿时就不写。
完整规范和交付时要附的「平台自检」清单见 `references/platforms.md`，两个都发的出两版（落款联系方式、封面尺寸、发布文案不同）。

工作目录：装机时约定的目录（本机是 `/Users/beiningli/Desktop/自媒体`）。
环境没装过？先按 `references/setup.md` 走一遍装机清单。

产物目录约定：
- `remotion-edit/public/newlaunch/<YYYY-MM-DD>-<slug>/` — script.json、shots/、vo/、captions/、manifest.json、cover.png（目录名叫 newlaunch 是历史原因，这条「非 Penny」渲染线的所有片型都放这里）
- `成片/<YYYY-MM-DD>-<slug>/` — 成片 mp4、`封面/`、发布物料.md
- `references/profiles/<代号>/` — 用户档案 + 他的原始素材（形象照、声音样本）

## 0. 每次先查档案（这一步是本 skill 的灵魂，不许跳）

档案在 `references/profiles/<代号>/profile.md`。每次被调用：

1. **只有一份档案** → 默认就是他，直接往下走。
2. **有多份档案** → 问一句这条片是给谁出的。
3. **一份都没有** → 这是首次使用，**先建档再出片**。读 `references/onboarding.md`，
   把要收的东西**一次性列全**发给用户（别挤牙膏一样一条一条问），能收多少收多少，
   记录进档案，再继续。
4. **档案在但字段缺** → 只问缺的那几样。**CEA 号空着不算缺**——它是可选项，他没给就不问、不催，
   只在交付时提醒一句正式发布按规矩要挂。视觉风格没定过的，补跑一次风格样片让他挑（`references/onboarding.md` 第 5 节）。

| 素材 | 用来干嘛 | 缺了怎么办 |
|---|---|---|
| 上屏姓名（他自己定的写法） | 落款卡 + 封面 | 必问 |
| 形象照（正面半身、背景干净） | 片尾落款卡头像 + 封面右下抠图 | 必问。实在没有：出片可以，但没有落款卡和带脸封面，要跟他说清楚这版是残的 |
| 声音样本 ≥15 秒 | 克隆声口播（本地或云端都要它） | 必问。急着看效果可先用 MiniMax 现成音色出 demo 版，正式版必须等克隆完 |
| CEA 注册号 + 经纪行 | 片尾落款（可选） | **可选，不强制**。建档消息里带一句「有就给，正式营销物料按规矩要挂；不给也能出片」，他没给就跳过，**不追问、不阻塞出片**。他给了才挂进片子 |
| 视觉风格 | 字体、字幕、数字卡、动画、配色整套设计语言 | 建档时跑一次风格样片让他从 5 套里挑（抖音爆款 / 小清新 / 苹果发布会 / 新闻资讯 / 杂志编辑）（`references/onboarding.md` 第 5 节）。他说「你定」就按客群定；**五套都不喜欢就问几个问题或让他丢一张喜欢的图，用 `scripts/add-style.mjs` 生成一套他自己的**（同节第 4 条），渲样片给他看，不满意继续调。记进档案，整个号统一用 |
| 默认 BGM | 每条片的配乐 | 跟风格走即可，他有偏好就记进档案。每条片可按选题换一首（曲库表见 `remotion-edit/public/music/bgm/README.md`） |
| 固定封面版式 | 每条片的首图 + 首帧 | 第一条片时用他的头像和底图渲四种版式让他挑（`references/onboarding.md` 第 7 节），之后每条片固定用，只换标题和底图，默认放首帧 |
| 固定片尾（版式 + 行动句） | 每条片的结尾 | 建档时用他的头像渲三种版式让他挑（`references/onboarding.md` 第 6 节）。**之后每条片都带，不问不改**；他明确说改或不要才动 |
| 配音路线（本地 F5-TTS / MiniMax 云端） | 决定配音怎么跑 | 建档时问一次，两条路线的取舍见 `references/pipeline.md` 第 2 节。想先看效果再注册账号的，先走本地 |
| 联系方式（微信/电话） | 片尾引流 | 可选 |
| 客群定位（HDB/私宅、租/买、留学生/本地家庭） | 判断选题对他有没有用、落点怎么写 | 建档时问一次 |

**为什么这么较真：** 这些素材是编不出来的——没照片就渲不出落款卡，假装有只会报错或出一张空卡；
音色 ID 是克隆出来的不是猜出来的。问一次、存进档案，以后每条片都不用再问，这笔账很划算。
同理，**出片过程中任何时候发现缺了只有他能给的东西（一个数字、一张图、一句确认），停下来问，
不要替他编**。

## 1. 判断片型（只接这三类）

| 片型 | 例子 | 要他给什么 |
|---|---|---|
| 政策 / 新闻快讯 | 印花税调整、新盘开售、URA 数据 | 一条新闻（截图/链接/原文）就够 |
| 算账 / 对比 | 3900 vs 4200 怎么选、回报率拆账 | 一张表：对比对象、拆项、结论数字，外加「愿不愿公开这套房的真实数字」 |
| 常识科普口播 | 押金不是解约金、地契年限、验房清单 | 他常被问的问题 + 他自己踩过的坑（有细节才有人看） |

**房源实拍 / 探房 / 人设日常不接**——那要逐条看他的原始素材、编时间码、核穿帮，
是外包剪辑不是出片。婉拒并说明可以给拍摄清单和模板。新盘 e-book 出片是另一条线（newlaunch-shot）。

**一个例外：他自己的挂盘。** 他丢一条 PropertyGuru / CommercialGuru 挂盘链接进来说「用这个出条片」，
走下面第 1b 节——那是第四类片型（单盘介绍），但**只限他自己挂的那套**；别人的盘只出文字脚本，不出成品。

## 1b. PG 链接一键出片（他丢一个挂盘链接进来）

触发：一条 PropertyGuru / CommercialGuru 的挂盘链接 +「用这个出条片」「这个盘做条视频」。
片型是**单盘介绍**，属于上面那张表的例外，**只限他自己挂的那套**。
风格、BGM、字幕、片尾、封面、平台规范全部沿用第 2–6 步和 `references/platforms.md`，
这一节只写这个入口特有的东西。

### 前提（这个入口额外核对，缺「必须」就停下来先补）

| | 项目 | 怎么确认 |
|---|---|---|
| 必须 | 归属确认：这条链接是不是他自己的挂盘 | 见下面「第一句必须问」。**每条新链接问一次** |
| 必须 | 链接是单套房的详情页，不是搜索结果页或项目页 | 地址栏里有 `/listing/` 或 `/l/` 加一串 id；列表页 URL 抓不出单套资料 |
| 必须 | 档案齐（第 0 步那套：上屏姓名、形象照、音色、视觉风格） | `references/profiles/<代号>/profile.md` 这几项不为空 |
| 必须（出成品片才要） | 浏览器工具连着，**他自己的** Chrome 已登录 PropertyGuru | 「@Chrome 告诉我当前网页标题」能报出 PropertyGuru。用他自己的账号读他自己的页面，不经任何中转或代抓服务 |
| 可选 | 他自己拍的原图 / 原片 | 有原图优先用原图（挂盘页上的图被压过）；有视频素材那条线走 agent-cut |
| 可选 | 挂盘页截图或他手抄的资料 | 平台改版读不到字段时的退路，照下面那张表抄一样能出片 |

### 红线（这个入口特有，和文末那份「红线」一起生效）

1. **先确认归属，每条新链接确认一次。** 没确认是他自己的盘，就不下载照片、不渲成品片。不许拿上一条链接的答案放行，不许把答案记进档案或在会话里沿用。
2. **照片必须干净。** 别的中介的名片、姓名、CEA 号、头像，别家经纪行的 logo，平台或摄影公司水印，房主和路人的脸，门牌号和单元号特写——出现任何一样就**跳过那张**，不裁、不打码、不修掉再用。
3. **价格和面积必须和挂盘页一字不差。** 片子里出现的每个数字都要能在挂盘页上指着说「就是这个」；不四舍五入成「三百多万」，不换单位，不自己估。
4. **片尾挂他自己的 CEA 信息**（档案里那套）。挂盘中介的姓名、公司、电话、头像，一个字不进片子、封面和发布物料。
5. **不代发布、不代上传。** 片子出来在他电脑里；发不发、发哪里，他自己在他自己的 App 里做。

### 第一句必须问（不许跳，不许记答案）

拿到链接，**在读任何内容之前**先问这一句，原话可以照抄：

> 先确认一件事：**这是你自己的挂盘吗？**（挂盘页上写的挂盘中介就是你本人）
> 是 → 我读里面的资料和照片，直接给你出成品片。
> 不是 → 我只给你文字脚本和拍摄清单，不下载照片、不出成品片——别人挂盘的照片是人家花钱拍的，用了是侵权，平台也不允许。

判断只有两档，不留中间地带：

| 他怎么回 | 算哪种 | 做什么 |
|---|---|---|
| 「我自己挂的」「是我的盘」 | 自己的 | 走 **A 线**：读资料 + 读照片 + 出成品片 |
| 「同事的」「co-broke 的」「客户发我的」「网上看到的」 | 不是自己的 | 走 **B 线**：只出文字脚本 |
| 不回答、绕开、「差不多算我的」「我有他同意」 | 不是自己的 | 走 **B 线**，并把原因说一遍 |

- **每条新链接问一次。** 上一条他说「是我的」，不代表这一条也是。一次会话里丢五个链接就问五次。
- 「同事同意我用」也走 B 线：他同事能同意的只是他自己的东西，照片版权多半在摄影师或卖家手上，同意不了。要出成品片就让同事**把原图原样发给他**，当自有素材走（图进 `shots/`，有视频转 agent-cut）。
- 他先说不是、后来改口说是的：让他把挂盘页上他本人那条中介信息念出来（姓名 + CEA 号，和档案对得上）再走 A 线。

### 第 1b-1 步：读挂盘页（A 线读全套，B 线只读文字不碰照片）

| 要读的 | 干嘛用 | 注意 |
|---|---|---|
| 项目名 | 标题卡、封面、口播开头 | 用挂盘页上的官方写法，别改成简称 |
| 路名 | 地段那段 | **只到路名，不放门牌号和单元号**（卖家隐私，也是给他自己留退路） |
| 报价 | `stat` 大数字、封面副行 | 原样写 |
| 面积 sqft | `stat` | 挂盘页写的那个数；strata 还是 built-up 就照它写，不换算 |
| psf | `stat`（可选） | 挂盘页给了就用它的；自己算的要在画面角标写「按挂牌价 ÷ 面积」 |
| 房型（房数 / 卫数 / 户型） | `bullets` | 面积和房数明显对不上（1,001 尺标 4 房）先问他，不自己圆 |
| 楼龄 / TOP 年份 | `bullets` | 写 TOP 年份，不写「X 年房龄」——那种数字明年就过期 |
| 地契（Freehold / 999 年 / 99 年 + 起算年份） | `bullets` | 999 年和 Freehold 不是一回事，原样写 |
| 地铁站 + 步行分钟 | `bullets`、口播 | 挂盘页写几分钟就几分钟，不自己按地图估 |
| 家具和装修状态（fully furnished、renovated 哪一年） | 口播卖点 | 说「刚装修」要有年份，没有年份就不说 |
| 可入住时间 / 租约状态（vacant、tenanted till…） | `bullets`、口播落点 | 有租约就写清楚到期时间，不许含糊成「随时入住」 |
| 照片 | `shots/` | **只有 A 线下载**，规矩见第 1b-2 步 |

怎么读：在他已登录的标签页里打开详情页，从 `__NEXT_DATA__` 里取——
价格、面积、房数、地址在 `props.pageProps.pageData.data.listingData`，
地契 / TOP / 家具这类要点在 `data.detailsData.metatable.items`，照片在 `media` / `images` 类字段的 url 数组里。
装了 pg-cobroke 的，抓法和字段路径跟它「客户版房源卡」那一步完全一样，别重造。
**字段名平台会改**：读不到就不要猜——让他照上面那张表把资料贴给你，或发挂盘页截图，手抄一样能出片。
商业 / 工业挂盘（CommercialGuru）同一套流程，`bullets` 换成楼面 sqft、psf、类型（B1 / B2 / 办公 / 商铺）、地契、层高、装修状态、货梯，口播落点换成「能不能做这个用途」。

### 第 1b-2 步：照片、数字、片尾（这个入口特有的三条，照做）

**照片（A 线）**
1. 下载到 `remotion-edit/public/newlaunch/<YYYY-MM-DD>-<slug>/shots/`，每张记一行进 `shots/SOURCES.md`：文件名 ← 挂盘页 URL ← 抓取日期。
2. **逐张 Read 看过再用。** 撞上这一节红线第 2 条里任何一样就跳过那张，并在核对表里写跳了哪张、为什么。
3. 一条片用 4–8 张：封面图 + 客厅 + 主卧 + 厨房或卫浴 + 景观或外立面。干净的图不够 4 张就少放，或整条片改成文字卡版（`stat` / `bullets` / `title`）。**不要为了凑数用带水印的图，也不要上网找同项目别人拍的图。**
4. 不美化、不去杂物、不换天空：片子里的房子要和买家来看到的是同一套。

**数字**
1. 抓完回读一遍：报价、面积、psf、房数，逐个对挂盘页原值，对不上就重抓。
2. 每条片留一份 `脚本/NN_<项目>_挂盘核对表.md`（格式见下面「输出格式」），每个上屏数字写清挂盘页原值和**抓取时间**。
3. 片子里要是出现印花税、月供、租金回报这类数字：标出处（IRAS / MAS / 具体银行页面）和「截至日期」，并在交付物料里带一句「税率和规则会变，用之前对一眼官网」。

**片尾和封面**
1. 片尾用档案里的 `signoff.layout` + `signoff.cta` + 他自己的姓名 / CEA 号 / 经纪行，CEA 号没给就空着（第 4 步的规矩，不变）。
2. 封面底图只能从这条片里挑干净的那张；一张都没有就用纯色版式，别拿挂盘页的图硬上。
3. 分镜表照第 3 步发给他确认，**和挂盘核对表一起发**，他点头才配音渲染。

### 输出格式

**A 线（他自己的挂盘）**：产物和平常一条片一样（`成片/<slug>/` 下 mp4 + 两版封面 + `发布物料.md`），外加一个核对表文件：

```markdown
# 挂盘核对表 · <项目名>

挂盘链接：<URL>
抓取时间：<YYYY-MM-DD HH:MM>（新加坡时间）
归属：本人挂盘，<日期>由他本人确认

| 片里出现的数字 | 挂盘页原值 | 出现在哪 |
|---|---|---|
| S$… | S$…（原样） | 封面副行、第 3 段 stat、口播第 3 段 |
| … sqft | … sqft | 第 3 段 stat |
| S$… psf | 页面没给，按 报价 ÷ 面积 算 | 第 4 段角标 |

照片：用了 shots/01–05（← 挂盘页第 1、2、4、7、9 张）；跳过第 3 张（右下角有别家经纪行 logo）、第 6 张（有人脸）。
片尾：<上屏姓名> + <CEA 号 / 未提供> + <行动句>。挂盘中介的信息一个字没进片子。
发布前再看一眼：挂盘还在不在、价格有没有改。
```

`发布物料.md` 的数字核对表那一栏，来源写「PropertyGuru 挂盘页 <URL>，截至 <日期>」，并加一句：
**挂牌价和面积以挂盘页为准，截至 <日期>；改价或下架了这条片就别再发，重抓重渲。**

**B 线（不是他的挂盘，或他没确认）**：**只出一个文件**，`脚本/NN_<项目>_文字脚本.md`。不下载照片、不渲 mp4、不做封面图。里面七节：

1. **为什么这版只有文字**：照片是挂盘方的，用了侵权，平台也不允许；要成品片就用你自己挂的盘，或让挂盘方把原图发给你。
2. **分镜表**：每段一行，左边口播原文，右边**要他自己拍什么**（「客厅从门口往里横移，5 秒」），右边不许出现「用挂盘页第 2 张图」。
3. **拍摄清单**：8–10 个镜头，竖屏、每个 5 秒，注明避开门牌号和单元号、避开别人的脸和别人的名片。
4. **封面文字**：两行、每行 ≤6 字 + 一组硬数字；底图留空等他自己拍。
5. **片尾行动句**：档案里那句。
6. **发布文案候选**：按平台分栏，规矩同第 6 步和 `platforms.md`。
7. **数字来源表**：每个数字 → 挂盘页 URL → 截至日期，外加一句「数字以挂盘方为准，发之前自己核一遍」。

示例输出（A 线 + B 线各一份）见 `examples/PG链接一键出片_示例输出.md`。

### 常见卡点

| 现象 | 原因 | 怎么解 |
|---|---|---|
| 抓出来是一堆房源，不是一套 | 他复制的是搜索结果页或项目页的 URL | 让他在 PG 上点进那套房、再复制地址栏；或把 listing id 报给你 |
| `__NEXT_DATA__` 读不到、字段是空的、跳去登录页 | 平台改版或那个标签页没登录 | 在他已登录的标签页里读；还是不行就让他照第 1b-1 步那张表把资料贴过来，手抄出片，**别猜数字** |
| 照片张张带水印或别人的名片 | 这盘不是他挂的，或他的挂盘图是摄影公司加了 logo 的 | 只做文字卡版，或让他拿原图（摄影公司那份）；原图到手当自有素材走 |
| 渲完发现价格和挂盘页不一样 | 中途改价，或抓到的是缓存 | 重抓核对：只有画面上的数字错就改 script.json + manifest.json 重渲；口播也念了价格就那一段重配音 |
| 他说「这是我同事的盘，他同意了」 | 同意的人不是照片版权方 | 照旧走 B 线，把原因说清楚；要成品片让同事把原图原样发给他 |
| 片尾出现了挂盘中介的名字 | 从挂盘页抓资料时把 agent 字段一起带进了 script.json | 抓的时候就别取 agent 相关字段；渲完 `grep` 一遍 script.json 和 manifest.json 里有没有挂盘中介的姓名、公司、`+65` |

### 这一版做不到什么（跟他说清楚）

- **不代发布、不代上传**：视频号、小红书、PropertyGuru、99.co，一个都不碰，成片只落在他电脑里。
- **不自动搬别人的盘**：不是他的挂盘就没有照片、没有成品片，这条不商量。
- **不改挂盘页**：不帮他改价、改文案、上下架。挂盘描述要重写是另一条线（写 listing description 那个技能），不在这里。
- **不批量**：一条链接一条片。要一次扫很多盘那是 pg-cobroke，不是这里。
- **不碰合同、LOI、法律和税务意见**：印花税这类数字只给出处和截至日期，怎么算以官网和他的律师为准。
- **不修图**：不去杂物、不换天空、不把缺点抹掉。
- **不保证字段路径长期有效**：平台一改版就要回退到手抄那条路。

## 2. 调研核实（不可跳过）

每个要上屏的数字都要有一手出处。可信度分级、来源坑、数字核对表的做法见
`references/writing.md` 的「调研与核实」节。核不到的数字删掉，不许估。

## 2b. 配图：没有素材就主动去找真实照片（新闻 / 科普 / 算账片默认要做）

他没给图、选题又是新闻、政策、地段、科普这类时，**不要整条片都是纯色字卡**：主动搜真实照片当画面和底图，
数据卡（`stat` / `bullets` / `title`）也垫一张相关照片（`"bg": "shots/xxx.jpg"`），观众看到的是新加坡的楼、地铁、街景，
不是一块色板。

1. **列关键词**：按分镜表每段写 1–2 个英文搜索词（图库英文结果好得多）——地名（"Bishan Singapore"）、
   建筑类型（"Singapore HDB flats" / "Singapore condominium"）、交通（"Singapore MRT station"）、
   政策主体（"Singapore Housing and Development Board building"）。人名、公司 logo、新闻现场照片不搜。
2. **搜**：`cd news-pipeline && python3 fetch_images.py search --out ../remotion-edit/public/newlaunch/<slug>/shots -q "<词1>" -q "<词2>" …`
   只出能商用、能改的授权（CC0 / 公有领域 / CC BY / CC BY-SA / Pexels / Unsplash），NC、ND、来源不明、新闻社图一律不出。
   政策新闻有官方页面（gov.sg、URA、HDB、发展商自己的新闻稿）可以加 `--page <URL>` 把页面配图列进候选，**标成「官方图，确认条款」，不默认用**。
3. **挑**：Read `shots/candidates/sheet.jpg`，按画面和这一段说的是不是同一件事来挑——讲碧山就用碧山，不拿别区的楼凑；
   有人脸特写、车牌、门牌号、别人家阳台里的人，跳过。挑好 `python3 fetch_images.py pick --out <同上> 3 7 12 --as hdb,mrt,bishan`，
   它会改名放进 `shots/`，并把出处写进 `SOURCES.md`、署名写进 `CREDITS.txt`。
4. **用**：`photo` 段用 `"source": "<CREDITS 里那行>"`；数据卡垫图用 `"bg": "shots/hdb.jpg", "bgSource": "<那行>"`。
   **CC BY / BY-SA 的图必须署名**：画面角标 + 发布物料第 4 项都要写；CC0 / Pexels / Unsplash 不强制但照样写来源。
5. 一条 60 秒片 4–8 张就够；同一张图别在两段里都当主画面。搜不到贴题的就用纯色字卡，**不拿不相关的图凑数**。

**不适用**：PG 挂盘片（第 1b 节）只用他自己的挂盘照片，不上网找同项目的图；他自己给了图就先用他的。

## 2c. 他给了参考片：学它的风格（配色、字体、字幕、动画）

他丢来一条喜欢的视频（别人的爆款、他自己以前的片）说「照这个风格做」，或建档时说「想要这种感觉」：

1. `cd remotion-edit && python3 scripts/learn_style.py <参考片> --out ../风格/<名字> --name <名字>`——
   量字幕位置 / 字号 / 颜色 / 描边或底框 / 关键词高亮色、整体配色和强调色、剪辑节奏，出 `style_brief.md` 和几张对照图。
2. **Read 那几张图自己判断**：`captions.jpg` 看字体（黑体 sans / 宋体 serif / 圆体 rounded）和粗细；`entry_*.jpg` 看字幕怎么出来
   （弹出 pop / 淡入 fade / 上滑 slide / 逐字）；`cut_*.jpg` 看转场。把判断填进 brief 里那条 `add-style.mjs` 命令（`--font`、`--motion`）再跑，
   生成一套自定义风格；`--caption` 已按量到的字幕样式填好，看图不对就改。
3. 渲风格样片给他看（`npx remotion render StylePreview-<id> out/style-previews/<id>.mp4`），他说像了才用；script.json 的 `style` 填这个 id，
   记进档案「视觉风格」，以后整个号统一用。
4. **只学样式，不抄内容**：参考片里的账号名、水印、logo、口头禅、具体文案一个都不搬；brief 里「固定文字」那一栏就是提醒你别抄的东西。
   字体只能用他电脑上有的（引擎自带黑体 / 宋体 / 圆体三类），参考片用了特殊商用字体就选最接近的一类并告诉他。

## 3. 写稿 → 先给他看，确认了再配音渲染

写完稿子**不要直接往下跑**。先把一张「分镜表」发给用户：每段一行，左边口播原文，右边这段画面上会出现什么
（标题卡 / 大数字 / 哪张图 / 要点列表），外加封面两行文字、片尾行动句、配乐曲名。用户说「可以」才进第 4 步；
他改哪段就改哪段再确认。这一步省的是重配音、重渲染的时间和 token，一次确认比返工便宜得多。
用户提示词里明确写了「直接做，不用确认」才跳过。


按 `references/writing.md` 写：白话（聪明的 12 岁孩子能复述）、总长 45–75 秒、
一句 ≤15 字、**中性口语**（别套任何现成博主的语言指纹——他的口头禅从他自己的语音样本里听，
听不出来就写中性）、CEA 禁语一条不碰、多音字自检必过。
- **字幕永远一行，不折行。** 一条字幕 ≤14 字（大字幕段 ≤11 字），放不下就拆成两条字幕，不是让它换行。引擎断行规则按这个设的，渲完抽帧看到两行字幕就是稿子里那句太长，改稿重配。

写完存 `脚本/NN_主题_脚本.md`（逐段口播 + 数字核对表 + 多音字自检记录）。

## 4. 配音 + 渲染

按 `references/pipeline.md` 走：script.json → 克隆声 TTS（按档案里的配音路线：本地 F5-TTS
或 MiniMax 云端，坑都写在那个文件里）→ Remotion 渲染 → 抽帧自查。
script.json 顶层 `style` 填档案里的视觉风格。**`music` 每条片都要你主动选，不问用户**：看这条片的选题、口播情绪、画面素材
（新闻政策 / 数据 → `09_light_relaxed` 或 `01_business_promo`；家庭自住、租房常识、暖心 → `02_warm_healing` / `10_guitar_afternoon`；
避坑、对比、有梗 → `03_funk_upbeat` / `04_vlog_indie_pop`；豪宅新盘 → `05_guofeng_grand`；地段周边 → `06_travel_loop`；
图片快闪 → `07_beat_drop_rock`），曲库全表在 `remotion-edit/public/music/bgm/README.md`，学员自己加的曲子也在里面，一并纳入挑选。
拿不准才落回风格默认曲。用户说「换温馨一点的」之类，按情绪换一首重渲即可。交付物料里写明用了哪首。
**用户要加自己的曲子**（「把这个文件夹里的音乐加到背景音乐里」）：按 `references/pipeline.md` 第 1 节「加曲子」跑 `scripts/add-bgm.mjs`，
每首问一句风格和适合什么内容（他不说就自己听一遍写），版权提醒一句是他自己的。
片尾用档案里的固定版式和行动句（`signoff.layout` + `signoff.cta`），每条片都带，不问不改；用户明确说「这条片尾改成……」才换，说「不要片尾」才写 `"ending": false`。
CEA 号有就挂、没有就空着，不问。

走 MiniMax 的要**逐段核语速**：短句多的段会随机拉长节奏，同段重跑能差 25%。
偏慢的段同参数重摇留最快的一条（别用 `--speed` 补），仍不达标用 `atempo ≤1.12` +
字幕时间轴同比缩放。合格带用**该中介本人**的实测语速 ±10%。完整流程见 `news-shot/SKILL.md` 第 6 步。

## 5. 封面

用引擎自带的封面合成，版式取档案里的 `封面版式`（首次没有就先按 `references/onboarding.md` 第 7 节渲四种让他挑）：
`bash scripts/cover-previews.sh render <slug> '<props>' <版式id>`，标题两行、每行 ≤6 字、说观众关心的事，副行一组硬数字，
底图用这条片里版权干净的那张，头像用档案里的抠图。
**封面底图必须是真实照片**（他给的图，或第 2b 步挑出来的那几张里最能代表这条片的一张），不用纯色、渐变、图表或动画帧当封面底；
`plain` 版式只在一张能用的照片都没有时才用，并跟他说一句「这次没找到合适的真实图片，封面先用纯色版」。出 `cover.png`（首帧 + 视频号）和 `cover_1440.png`（小红书），
`coverImage` 默认填 `cover.png`。**不要用设计C**（那是 Penny 新闻号的版式）。渲完 Read 看图：字没撞人像、没超框。

## 6. 交付（不代发）

发成片 + 两版封面，外加 `成片/<slug>/发布物料.md`：

1. 视频号/朋友圈标题 2–3 个 + 文案 + #话题（用户发视频号时）
2. 小红书标题 2–3 个 + 正文 + #话题，正文和话题里不出现任何联系方式（用户发小红书时）
2b. 「平台自检」清单（`references/platforms.md` 第 4 节），写明这条片针对该平台改了什么
3. 逐段口播全文（他可能想自己重录）
4. 数字核对表：每个上屏数字 → 出处链接 → 可信级别；用了网图的，把 `shots/CREDITS.txt` 整段贴上（CC BY / BY-SA 必须署名）
5. 提醒几句：时效词（「昨天/今天」）只在当天发才准；网图版权他最终把关；
   挂了 CEA 号的，号码和经纪行是他给的，发之前自己再核一遍；没挂的，
   提醒一句正式发布按规矩要挂——挂不挂始终是他的决定，说一次就够，别每条片都念
6. 配乐用了哪首（曲库 id + 曲名），加一句：曲子来自剪映曲库，发视频号/小红书等平台前自行确认授权

发布全部由他自己来。不代发。

## 红线（不分片型，条条适用）

**红线的用法是提醒，不是代改。** 发现踩线（比如他给的数字像投资建议）
就停下来指出来，怎么处理由他决定——不要自作主张替他把合规元素（CEA 号之类）加进视频。
唯一例外是你自己写的稿子：禁语在写的时候就不要写进去，那是作者的责任不是替用户改。

- **收益承诺一个字不许有**：「稳赚」「保值增值」「肯定涨」「回报 X%」全是 CEA 广告规矩的雷。
  算账片的措辞只能是「这套房的账是这样」，不能是「建议你买」。
- **法规讲错一次比不发还糟**：租约、印花税、地契这类内容，每条留一句来源。
- **「学区房」不许说**：新加坡是 1 公里内优先抽签，只能说「在 X 小学 1 公里内」。
- **声音克隆必须本人授权**：建档时问清楚，记录在档案里。
- **别人的挂盘不出成品片**：PG 链接出片前先问「这是你自己的挂盘吗」（每条链接问一次），
  不是他的就只出文字脚本，不下载照片、不渲片——挂盘照片是挂盘方花钱拍的（第 1b 节）。
- **他给的数字要他确认**：成交价、租金这类他报的数，交付物料里注明「以你提供的数字为准」。
